# 鱼鱼找鸡（AstrBot 插件）

在 QQ 里引用一张图，发 `/鱼鱼找鸡`，机器人会用谷歌 Lens、SauceNAO、trace.moe 反查这张图，
尽量找出图里 coser 的社媒账号（推特 / 微博 / B 站 / Instagram / Pixiv）。

> 识图引擎来自开源项目「鱼鱼找鸡 v1.0.0」（作者：小鲸鱼，MIT 许可）。本仓库把它改成了 AstrBot 插件，
> 并删掉了原版里不安全或用不上的部分，见下文「和原版的区别」。

## 怎么用

1. 在群里或私聊里**引用（回复）一条带图的消息**，发送 `/鱼鱼找鸡`（也可以发 `/找鸡`）。
   把图片和指令放在同一条消息里发也行。
2. 机器人先回「收到，开始找鸡」，20 秒到 2 分钟后发结果。
3. `/鱼鱼找鸡 帮助` 查看说明。

**默认只有 AstrBot 管理员能用。** 想给别人用，在插件配置里把「谁可以使用」改成 `whitelist`，
再填允许的 QQ 号或群号；改成 `all` 就是所有人都能用（不建议在大群开）。

## 安装

在 AstrBot 管理面板 → 插件 → 安装插件 → 从链接安装，填：

```
https://github.com/robot234/astrbot_plugin_fish_find_chicken
```

需要的环境：

- **Node.js 20 或更新版本**（必须）。AstrBot 官方 Docker 镜像里一般已经有 `node`；
  没有的话装一个，或者在配置里填 `node_path`。
- **Chrome / Edge / Chromium 浏览器**（谷歌 Lens 和百度识图要用；没有的话这两个引擎会被跳过，其它照常）。
  插件会自动找系统里的浏览器；在 Docker 里找不到时，会借用其它插件下载的 Playwright 浏览器
  （例如 `astrbot_plugin_blablalink`）。也可以在配置里填 `browser_path`。
- **能访问谷歌**（Lens 需要）。连不上谷歌时，在配置里填 `proxy`，例如 `http://127.0.0.1:7890`。
  用 Clash/mihomo 的 fake-ip 模式时保持「兼容 Clash fake-ip」开着。

## 配置说明

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 谁可以使用 `access_mode` | `admin` | `admin` 只有管理员；`whitelist` 管理员 + 白名单；`all` 所有人 |
| 允许的 QQ 号 / 群号 | 空 | 白名单模式用 |
| 识图引擎 `engines` | lens, saucenao, tracemoe | 还可以加 iqdb、baidu |
| 单个引擎超时 | 45 秒 | |
| 最多报几个账号 | 3 | |
| 只报名字对得上的账号 | 开 | 关掉误报会变多 |
| 每人冷却时间 | 30 秒 | 管理员不受限 |
| 浏览器代理 / 浏览器路径 / Node 路径 | 空 | 留空自动 |

## 和原版的区别

- **删掉了「读本机文件」**：原版 QQ 指令 `/鱼鱼找鸡 <路径>` 会把服务器上任意文件读出来上传，谁都能触发。
  本插件只处理聊天里的图片（网址或 base64），本机路径一律不读；引擎入口也只接受插件临时目录里的文件。
- **删掉了用不上的残留代码**：读取 `~/.dsh` 凭据并调用 DeepSeek 的网页搜索、公网临时图床（litterbox）、
  「猫猫云」VPN 和修改 Windows 系统代理的代码。
- **加了权限**：默认只有管理员能用，可选白名单；加了每人冷却和「同时只查一张」。
- **支持 Linux / Docker**：浏览器能在树莓派 / Docker 里以 root 运行；结束或超时都会关掉浏览器，不留后台进程。
- **兼容 Clash fake-ip**：原版会把 198.18.x.x 当内网拦掉，导致开着 Clash 的机器一个引擎都用不了。
- 图片只发给固定的识图网站（谷歌 Lens、SauceNAO、trace.moe，以及你自己开启的 iqdb / 百度），不发给其它地方。

## 请注意

- 结果来自公开的识图网站，可能不准，也可能找错人，仅供参考。
- 反查别人的照片涉及隐私，请只在熟人小群里用，不要用来骚扰、人肉任何人。
- SauceNAO 等网站有免费次数限制，查太快会返回 429，过一会儿就好。

## 开发者备注

`engine/` 目录是用 `tools/build_engine.mjs` 从原版生成的（已提交，安装时不需要再生成）：

```
node tools/build_engine.mjs <原版解压目录>
```

`engine/cli.mjs` 是插件专用入口，Python 侧把图片写到 `<plugin_data>/tmp/` 后调用它，结果是一行 JSON。
